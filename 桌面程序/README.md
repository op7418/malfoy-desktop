# Miss Malfoy · 马尔福小姐（AI 女友桌面 Demo）

一套代码（`app/`），打包成两个平台：

| 平台 | 形态 | 位置 |
| --- | --- | --- |
| macOS | 安装包 `.dmg`（Electron），菜单栏常驻 | `mac/dist-v7/Miss Malfoy-0.1.0-arm64.dmg` |
| Windows | Wallpaper Engine「网页壁纸」工程 | `wallpaper-engine/` |

## 玩法

- **桌面常驻**：她入场 → 躺在沙发上看书。每隔 10–24 秒随机做一个小动作（翻书 D2 / 伸懒腰 D3），每个动作的首尾帧都是同一张锚点图，所以衔接是无缝的。晚上 23 点以后她会睡着（D5），点一下叫醒。
- **点她**：播放 D4「Stop staring.」，好感度 +1（45 秒冷却，冷却期间只回一句台词气泡）。
- **剧情**：第一章分段播放，1-2 结束后出互动选项（12 秒不选默认 A），A/B 走不同分支再汇合到 1-3、1-4。第一次看完好感度 +10，选 B 额外 +3、选 A 额外 +1。
- **冥想盆**：看过的片段会存成回忆，可以随时重看；没走过的分支显示「？？？」。
- **衣橱**：好感度达到 20 解锁「居家装扮 · 扶手椅」（D6 入场、D7 喝茶）。睡衣装扮（60）和第二章（40）先占位。
- **声音**：默认静音（当壁纸不打扰）。点「声音」打开后，有环境声和一首循环的钢琴 BGM（Suno「Hush, Piano Alone」）；进剧情时 BGM 暂停。
- **称呼**：好感度越高，她对你的称呼越亲近（转学生 → 你 → 你的名字）。

**录屏用的快进**：连点左上角「MISS MALFOY」5 次（或按 Shift+Alt+M），好感度 +10。按 Shift+Alt+R 清空存档。

## macOS

1. 双击 dmg，把 Miss Malfoy 拖进「应用程序」。
2. 第一次打开：安装包没有签名，需要**右键 → 打开**，再点一次「打开」（或者到 系统设置 → 隐私与安全性 → 仍要打开）。
3. 打开后没有 Dock 图标，菜单栏会出现一个 🐍：
   - **和她互动…**：切到可点击的全屏互动模式；按 Esc 回到壁纸模式。
   - **重新入场**：重播入场动画（录屏用）。
   - **开机时自动启动**。

为什么分两种模式：macOS 的动态壁纸窗口放在桌面图标下面，点击会被桌面接走，所以壁纸模式只负责播放，互动要从菜单栏切出来。

开发：`cd mac && npm start`；重新打包：`npm run dist`。改了 `app/` 里的内容后，打包前会自动同步。

## Windows（Wallpaper Engine）

1. 把 `wallpaper-engine` 文件夹拷到 Windows 电脑上。
2. 打开 Wallpaper Engine → 左下角「壁纸编辑器」→「创建壁纸」→ 选这个文件夹里的 `index.html`。
3. 编辑器里确认属性（显示界面 / 壁纸声音 / 音量）后，「文件 → 应用壁纸」。想发布到创意工坊，就在编辑器里点「分享」。
4. 要点击她，需要在 Wallpaper Engine 设置 → 常规 里打开「鼠标输入」。

Wallpaper Engine 里没有键盘，快进好感度请用「连点名字 5 次」。

## 静止循环（不动时画面也在动）

生成视频的最后几帧画质会明显下降，所以动作片段不播到最后一帧：结束前 0.45 秒淡出，露出底下的「静止循环」。静止循环用的是高清首帧（就是锚点图），只有壁炉火光那一块在动，首尾无缝，一直循环播放。

| 文件 | 做法 |
| --- | --- |
| `media/ambient-sofa-a.mp4` | D8（她轻轻呼吸看书，环境在动）0.6–14.6 秒，结尾与开头交叉淡化 0.6 秒 |
| `media/ambient-sofa-b.mp4` | D9（她完全不动，环境在动），同上 |
| `media/ambient-sleep.mp4` | 底图 D5 第 5.42 秒（结尾里最清晰的一帧）+ D3 的壁炉火光 |
| `media/ambient-armchair.mp4` | 底图 D7 首帧 + D7 的壁炉火光 |

沙发场景每循环完一轮，就从 a / b 里随机挑下一段，0.6 秒交叉淡化。

重新生成：

```bash
# 有"环境在动"的整段片段时：输入  输出  循环秒数  交叉淡化秒数
tools/make-loop.sh D8.mp4 app/media/ambient-sofa-a.mp4 14 0.6
# 只有静帧时：火光来源  底图来源  输出  遮罩 x:y:w:h（4K 像素）  循环秒数  [底图取第几秒]
tools/make-ambient.sh D3.mp4 D5.mp4 app/media/ambient-sleep.mp4 3280:640:560:860 5 5.417
```

遮罩只盖火光，不要碰到人物，否则羽化边缘会带出别的片段里她的动作。

## 换素材

所有路径、台词、字幕时间、解锁阈值都在 `app/data.js`。比如 D8 补好以后：放进 `app/media/D8.mp4`，然后在 `scenes.armchair.idle` 里加上 `"media/D8.mp4"`。
